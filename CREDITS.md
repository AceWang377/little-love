# References

- [SEN memory game](https://github.com/sen-ltd/memory-game): reference for card matching, difficulty, and keyboard-friendly interactions.
- [Phaser official examples](https://github.com/phaserjs/examples): reference for pointer input, frame-based rendering, and collection games. No example game assets were reused.
- [Birthday Website Gift](https://github.com/sahandsame/Birthday-Website-Gift): inspiration for a playful path to a personal surprise.

These references informed mechanics only. The implementation, text, and vector drawings are original. The envelope illustration was retained from the owner's original “A little smile” game.
